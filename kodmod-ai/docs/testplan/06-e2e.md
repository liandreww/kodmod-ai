# Stage 6 — End-to-End (E2E) User Journey

**Tujuan.** Merangkai perjalanan pengguna nyata dari ujung ke ujung (REST + graph + DB +
memory), **text-mode**, memverifikasi hasil yang dilihat/didengar pengguna termasuk
**jaminan aksesibilitas** (tanpa referensi visual, kalimat pendek, angka dieja, SSML).

**Sifat gate.** Blok. 2–5 menit (varian `@real_llm` di-skip default).

**Framework.** `httpx.AsyncClient(base_url="http://localhost:8000")` — HTTP sungguhan ke
container `api` (bukan in-process), dijalankan native di host. Container `api` default
memakai `llm-stub`. Varian `@real_llm` (2–3 journey inti) butuh container `api` dinaikkan
ULANG dengan provider nyata di env sebelum `docker compose up`:
`KODMOD_LLM_PROVIDER=anthropic ANTHROPIC_API_KEY=... docker compose -p kodmod-test -f
docker/docker-compose.test.yml up -d --build api` — **tetap text-mode**
(`STT_ENABLED=false`, `TTS_ENABLED=false`); test itu sendiri di-`skip` kecuali
`KODMOD_RUN_REAL_LLM=1`.

**Entry.** Stage 5 hijau; container `api` up dan `/live` 200. **Exit.** Semua journey hijau
kecuali yang bergantung fitur kuis (`xfail(strict)` sampai #1/#5/#6/#11 beres) dan classroom
(#20).

**Lokasi.** `tests/e2e/`. **Marker.** `e2e`, `db`, `redis`, (`real_llm`).

## Journey

### KM-E2E-001 — Onboarding + Tutoring  `[e2e]` `[real_llm variant]`
1. `POST /student` body valid → 201, simpan `student_id`.
2. Mint JWT student (`auth_headers`).
3. `POST /voice/text` `text="tolong jelaskan apa itu pecahan"` → 200.
**Asersi:**
- `response_text` non-kosong; `audio_uri == ""` (TTS off).
- **0** kecocokan pola `_VISUAL_REFS` (id+en) pada `response_text`.
- **0** markdown (`**`, `#`, backtick, bullet).
- Setiap kalimat ≤ `settings.MAX_SPOKEN_SENTENCE_WORDS` (22) kata.
- Angka desimal dieja (`3.2` → `3 titik 2`) bila ada.
- Ada `<break .../>` bila kalimat > 1.
4. `POST /voice/text` `text="ulangi"` → `response_text` identik dengan langkah 3 (via
   `store_last_response`/`fetch_last_response` atau jalur repeat router).
**Oracle:** `agents/accessibility_agent.py` regex + `settings`.
**Bug ref:** #1 (`/voice/text` `student.profile`) → seluruh journey `xfail(strict)` sampai beres.

### KM-E2E-002 — Siklus Kuis Penuh  `[e2e]`  → `xfail(strict)` (#1,#5,#6,#11)
1. `POST /quiz/start` `{student_id, concept_id=<pecahan>, n_questions=3, difficulty="easy"}` → 200
   `QuizStartResponse` (`quiz_session_id`, `first_question`, `total_questions=3`).
2. Loop 3×: `POST /quiz/submit` `{quiz_session_id, question_id, student_answer}` →
   `QuizSubmitResponse` (`score`, `is_correct`, `feedback`); pada iterasi terakhir
   `quiz_complete=True` + `final_summary`.
3. `GET /analytics/student/{id}` → `avg_quiz_score` & `mastery` mencerminkan jawaban.
**Asersi:**
- Baris `quiz_sessions`, `quiz_questions`, `quiz_attempts` tertulis dgn `quiz_session_id`.
- `mastery_scores` untuk `pecahan` berubah sesuai arah jawaban (benar → naik, salah → turun),
  konsisten dengan rumus BKT (`LEARNING_RATE=0.25`).
- `misconceptions` terisi bila ada jawaban salah bertema.
- Semua `feedback` mematuhi jaminan aksesibilitas (lihat KM-E2E-010).
**Oracle:** `models/quiz.py`, `analytics/student_model.py`, alur graph target.
**Ini tonggak "siap dipakai".**

### KM-E2E-003 — Analytics Siswa  `[e2e]` `[real_llm variant]`
1. Seed beberapa `LearningSession` + `QuizAttempt` untuk siswa (via fixture atau endpoint).
2. `GET /analytics/student/{id}?window=month` → 200 rollup.
3. `GET /analytics/student/{id}/spoken` → 200 `{spoken, rollup}`.
**Asersi:**
- `spoken` dalam Bahasa Indonesia; frasa sesuai tier akurasi (≥0.8 / ≥0.6 / >0 / 0 sesi).
- `spoken` mematuhi jaminan aksesibilitas.
- `rollup` field lengkap (`overall_mastery`, `weak_concepts`, `engagement_index`, ...).
**Oracle:** `analytics/insights.py`, `analytics/aggregator.py`.

### KM-E2E-004 — Guru: Alert Kelas  `[e2e]`  → `xfail(strict)` (#20)
1. Seed classroom + 3 siswa dengan profil berbeda (1 kesulitan, 1 engagement rendah, 1 kuat).
2. Mint JWT teacher.
3. `GET /analytics/classroom/{id}/alerts` → 200 `{alerts, per_student, headline}`.
**Asersi:**
- Ada alert `warning` untuk siswa kesulitan; `info` untuk engagement rendah; `success`/tidak
  ada untuk siswa kuat (aturan `generate_teacher_summary`).
- `class_weak_concepts` top-5 benar.
**Oracle:** `analytics/insights.py`. Butuh `classroom_enrollment` (#20).

### KM-E2E-005 — RAG-Grounded Answer  `[e2e]` `[real_llm variant]`
1. `ingest_paths(["data/testplan/pecahan_mini.md"], concept_id=<pecahan>, language="id")`
   (dokumen mini di `test-data.md`).
2. `POST /content/retrieve` `{query:"apa definisi pecahan menurut modul", top_k:4}` → chunk
   dari dokumen itu muncul di `chunks`.
3. `POST /voice/text` `text="menurut modul, apa definisi pecahan?"` → `response_text`
   konsisten dengan isi chunk (kata kunci definisi muncul).
**Asersi:**
- `retrieved_docs`/`chunks` memuat `source` = dokumen yang di-ingest.
- Jawaban tidak mengklaim melihat gambar/tabel dari modul (aksesibilitas).
**Oracle:** `rag/ingestion.py`, `rag/retriever.py`, chunk konten.
**Bug ref:** bergantung #1 (`/voice/text`).

### KM-E2E-006 — Perintah Suara Meta di Tengah Sesi  `[e2e]`
1. Mulai tutoring (KM-E2E-001 langkah 1–3).
2. `POST /voice/text` `text="lebih pelan"` / `"berhenti"` / `"bantuan"`.
**Asersi:**
- `"berhenti"` → intent `stop` → jalur `end_speak→tts`, respons singkat penutup.
- `"bantuan"` → `help_text("id")` dikembalikan.
- `"lebih pelan"` → pacing di Redis (`set_pacing`) berubah (bila terhubung ke jalur itu) —
  bila belum terhubung, catat gap di traceability, `xfail`.
**Oracle:** `accessibility/voice_commands.py`, router.

## KM-E2E-010 — Jaminan Aksesibilitas Lintas Journey  `[e2e]` (parametrized)

Untuk **setiap** `response_text` / `spoken` / `feedback` yang dihasilkan di KM-E2E-001..006:

| Cek | Kriteria |
|---|---|
| Tanpa referensi visual | 0 match `_VISUAL_REFS` (ID: "lihat gambar/diagram/tabel", "seperti terlihat", "di atas/bawah"; EN: "see the figure", "as shown", "look at") |
| Tanpa markdown | 0 `**`, `__`, backtick, `#`, bullet `- `/`* ` di awal baris |
| Kalimat pendek | tiap kalimat (split `.?!`) ≤ 22 kata |
| Angka dieja | tidak ada `\d+\.\d+` mentah |
| SSML break | ada `<break` bila > 1 kalimat (opsional, sesuai `SSML_ENABLED`) |
| Bahasa | terdeteksi Indonesia (`detected_language="id"` di state akhir) |

**Oracle:** `agents/accessibility_agent.py`, `accessibility/simplifier.py`, `config/settings.py`.

## Catatan implementasi

- Setiap journey membuat siswa sendiri (isolasi); teardown rollback SAVEPOINT.
- `@real_llm` variant memakai `@pytest.mark.real_llm` + `pytest.mark.skipif(not os.getenv("KODMOD_RUN_REAL_LLM"))`;
  jalankan hanya KM-E2E-001, -003, -005 untuk membatasi biaya; assert **struktur & jaminan
  aksesibilitas**, bukan isi kalimat spesifik.
- Helper `assert_accessible(text)` di `tests/_fakes/accessibility_asserts.py` dipakai ulang
  di KM-E2E-010 dan Stage 4/7.
- Dokumen mini RAG (`data/testplan/pecahan_mini.md`, ~300 kata, 2 heading, 1 referensi
  "Gambar 1" untuk menguji stripping) dispesifikasikan di `test-data.md`.
